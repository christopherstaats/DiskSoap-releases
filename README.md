# Disk Soap

Safety-first macOS disk cleanup utility — caches, logs, Xcode builds,
simulator data, package-manager caches, duplicates, and local AI models,
with a 30-day recovery vault so nothing is ever destroyed outright.

This repo hosts **installer downloads only**.

## Download

Get the latest installer from
[Releases](https://github.com/christopherstaats/DiskSoap-releases/releases/latest)
(`DiskSoap-<version>.dmg`).

## Install

1. Open the DMG and drag **Disk Soap** into Applications.
2. Launch Disk Soap. The download is signed and notarized, so macOS
   Gatekeeper verifies it automatically — no warnings.

Requires macOS 14 (Sonoma) or later. Full Disk Access is recommended for
scan coverage outside your home folder.
